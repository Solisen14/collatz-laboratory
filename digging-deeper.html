01 DISCRETE DYNAMICAL SYSTEMS

Why Does Piecewise Matter?

The Collatz function has two rules, but it is still a single function. What makes its behaviour so interesting is that the rule applied next depends on the number produced by the previous step.

The Collatz function selects a rule according to whether the current positive integer is even or odd. If the number is even, we divide by 2. If it is odd, we apply 3n + 1. The output becomes the input for the following step, when the function chooses again.

This is why the piecewise definition matters. We are not following two independent sequences. We are repeatedly applying one function, while the orbit can move from one branch of its definition to the other.

The output determines the next rule

There is an immediate consequence of the odd-number rule. If n is odd, then 3n + 1 is always even. So every odd step must be followed by at least one even step.

However, dividing an even number by 2 can produce either another even number or an odd number. For example, 8 → 4 stays even, while 10 → 5 becomes odd. Consequently, the two rules need not alternate in a predictable pattern.

Increasing here, decreasing there

For every positive odd integer, 3n + 1 > n, so the odd step increases the value. For every positive even integer, n/2 < n, so the even step decreases it. An individual step is easy to understand. What happens over many steps is far less obvious.

In the orbit above, 3 → 10 increases, 10 → 5 decreases, and 5 → 16 increases again. Knowing the direction of a single step does not tell us the long-term behaviour of the sequence.

Collatz as a Discrete Dynamical System

A discrete dynamical system is a mathematical process in which a function is applied repeatedly, with each output becoming the next input. The word discrete means that the process advances in individual steps rather than continuously.

The Collatz function is one example. Both of its rules produce another positive integer, so the function maps positive integers back to positive integers: C : ℤ⁺ → ℤ⁺. Starting with any positive integer, we apply the appropriate rule to find the next number, then repeat.

The sequence of values generated from a particular starting number is called its orbit. Each individual step is straightforward, but predicting the long-term behaviour of an orbit is surprisingly difficult.

02 FOLLOWING THE SEQUENCE

Iterates and Orbits

We know what the Collatz function does to a number once. What happens when we keep feeding each result back into the function?

Applying a function again and again

In mathematics, applying a function repeatedly is called iteration. Each successive application gives us another iterate of the function.

Starting with 3, the first few iterates of the Collatz function are:

C(3) = 10First application

C²(3) = C(10) = 5Second application

C³(3) = C(5) = 16Third application

The superscript tells us how many times the function has been applied. For example, C²(3) means apply C twice, not square the number C(3).

We also write C⁰(3) = 3 for the starting value, before any steps have taken place.

After seven applications, the value is 1. We can write this as C⁷(3) = 1. But reaching 1 doesn't mean the process stops.

Following an orbit

In a discrete dynamical system, the forward orbit of a starting value follows what happens as we continue applying the function. We can show this using arrows, preserving the order of the values and any repetitions.

THE FORWARD ORBIT OF 3

3 → 10 → 5 → 16 → 8 → 4 → 2 → 1 → 4 → 2 → 1 → ⋯

Notice what happens when the orbit reaches 1. Because 1 is odd, the next value is 4. Then 4 goes to 2, and 2 goes back to 1. The orbit enters the repeating cycle:

1 → 4 → 2 → 1 → ⋯

Here is the question at the heart of the Collatz conjecture: Does every positive integer eventually reach 1 and enter this same cycle? That is what mathematicians suspect, but no one has proved it for every positive integer.

If we want a compact mathematical description, we can write the forward orbit as the ordered sequence C⁰(n), C1(n), C²(n), …. The order matters, and values can appear again when the orbit cycles.
