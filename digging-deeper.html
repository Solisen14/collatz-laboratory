01 DISCRETE DYNAMICAL SYSTEMS

Why Does Piecewise Matter?

The Collatz function has two rules, but it is still a single function. What makes its behaviour so interesting is that the rule applied next depends on the number produced by the previous step.

The Collatz function selects a rule according to whether the current positive integer is even or odd. If the number is even, we divide by 2. If it is odd, we apply 3n + 1. The output becomes the input for the following step, when the function chooses again.

This is why the piecewise definition matters. We are not following two independent sequences. We are repeatedly applying one function, while the orbit can move from one branch of its definition to the other.

The output determines the next rule

There is an immediate consequence of the odd-number rule. If n is odd, then 3n + 1 is always even. So every odd step must be followed by at least one even step.

However, dividing an even number by 2 can produce either another even number or an odd number. For example, 8 → 4 stays even, while 10 → 5 becomes odd. Consequently, the two rules need not alternate in a predictable pattern.

Increasing here, decreasing there

For every positive odd integer, 3n + 1 > n, so the odd step increases the value. For every positive even integer, n/2 < n, so the even step decreases it. An individual step is easy to understand. What happens over many steps is far less obvious.

In the orbit above, 3 → 10 increases, 10 → 5 decreases, and 5 → 16 increases again. Knowing the direction of a single step does not tell us the long-term behaviour of the sequence.

Collatz as a Discrete Dynamical System

A discrete dynamical system is a mathematical process in which a function is applied repeatedly, with each output becoming the next input. The word discrete means that the process advances in individual steps rather than continuously.

The Collatz function is one example. Both of its rules produce another positive integer, so the function maps positive integers back to positive integers: C : ℤ⁺ → ℤ⁺. Starting with any positive integer, we apply the appropriate rule to find the next number, then repeat.

The sequence of values generated from a particular starting number is called its orbit. Each individual step is straightforward, but predicting the long-term behaviour of an orbit is surprisingly difficult.

02 FOLLOWING THE SEQUENCE

Iterates and Orbits

We know what the Collatz function does to a number once. What happens when we keep feeding each result back into the function?

Applying a function again and again

In mathematics, applying a function repeatedly is called iteration. Each successive application gives us another iterate of the function.

Starting with 3, the first few iterates of the Collatz function are:

C(3) = 10First application

C²(3) = C(10) = 5Second application

C³(3) = C(5) = 16Third application

The superscript tells us how many times the function has been applied. For example, C²(3) means apply C twice, not square the number C(3).

We also write C⁰(3) = 3 for the starting value, before any steps have taken place.

After seven applications, the value is 1. We can write this as C⁷(3) = 1. But reaching 1 doesn't mean the process stops.

Following an orbit

In a discrete dynamical system, the forward orbit of a starting value follows what happens as we continue applying the function. We can show this using arrows, preserving the order of the values and any repetitions.

THE FORWARD ORBIT OF 3

3 → 10 → 5 → 16 → 8 → 4 → 2 → 1 → 4 → 2 → 1 → ⋯

Notice what happens when the orbit reaches 1. Because 1 is odd, the next value is 4. Then 4 goes to 2, and 2 goes back to 1. The orbit enters the repeating cycle:

1 → 4 → 2 → 1 → ⋯

Here is the question at the heart of the Collatz conjecture: Does every positive integer eventually reach 1 and enter this same cycle? That is what mathematicians suspect, but no one has proved it for every positive integer.

If we want a compact mathematical description, we can write the forward orbit as the ordered sequence C⁰(n), C¹(n), C²(n), …. The order matters, and values can appear again when the orbit cycles.

03 WHEN AN ORBIT REPEATS

Fixed Points and Periodic Orbits

We've learned how to follow an orbit, step by step. But what happens if it visits a number it has encountered before?

Because a function always gives the same output for the same input, once an orbit repeats a value, everything that follows must repeat as well. The orbit has entered a cycle.

Fixed Points: Staying Put

A fixed point is a value that remains unchanged when a function is applied. For a function f, this means finding an x such that f(x) = x.

Before returning to Collatz, let's start with a familiar function: f(x) = x².

To find its fixed points, we solve:

x² = x

x² − x = 0

x(x − 1) = 0

x = 0 or x = 1

We can see these two fixed points on a graph. Plotting y = x² alongside y = x, the graphs intersect exactly where the function's output equals its input.

Now let's follow the orbit starting at −1. Its first iterate is f(−1) = (−1)² = 1. Once the orbit reaches 1, it stays there, because f(1) = 1.

AN ORBIT THAT REACHES A FIXED POINT −1 → 1 → 1 → 1 → ⋯ The starting value −1 is not fixed. Its orbit lands on the fixed point 1 after one application.

A starting value doesn't have to be fixed for its orbit to eventually reach a fixed point. Keep that distinction in mind as we return to Collatz.

Does Collatz Have Any Fixed Points?

Recall that the Collatz function sends an even positive integer to n/2 and an odd positive integer to 3n + 1. Could either rule leave a positive integer unchanged?

We can check both possibilities.

CASE 1 · EVEN n

n/2 = n

n = 0

Zero is not in the domain of positive integers, so this does not give us a Collatz fixed point.

CASE 2 · ODD n

3n + 1 = n

n = −½

This is not an integer, so it cannot be a positive odd fixed point either.

Neither case works. Therefore, the Collatz function has no fixed points among the positive integers.

Not even 1! Since 1 is odd, C(1) = 4. So when an orbit reaches 1, the process doesn't stop or stay there.

What happens instead?

Periodic Orbits: Coming Back Again

A fixed point returns to itself after just one application of the function. But a value might return to itself after two, three, or more applications. Such a value is called a periodic point.

Mathematically, a point n is periodic when Cp(n) = n for some positive integer p. The period is the smallest such value of p.

Let's revisit 1:

1 → 4 → 2 → 1 → ⋯ After three applications of the Collatz function, we're back at 1: C³(1) = 1.

This is a periodic orbit of period 3. All three numbers in it are periodic points: starting from 4 gives 4 → 2 → 1 → 4, and starting from 2 gives 2 → 1 → 4 → 2.

They are three different starting places in the same repeating cycle.

Periodic or Eventually Periodic?

Now look again at the orbit starting at 3. The number 3 never returns, so it is not periodic. But after a few steps, its orbit enters the familiar cycle.

We call this eventually periodic behaviour: an orbit follows some initial steps before entering a repeating cycle.

Think back to f(x) = x². The orbit −1 → 1 → 1 → ⋯ eventually reaches a fixed point, while the orbit of 3 under Collatz eventually enters a three-number cycle. Both are eventually periodic.

There's a useful connection here: a fixed point is simply a periodic point of period 1. Collatz's familiar cycle has period 3 instead.

The Question We Still Can't Answer

We've shown that there are no positive integer fixed points of Collatz, and we've found one repeating cycle, 1 → 4 → 2 → 1. But is it the only possible long-term behaviour?

Could a positive integer enter an entirely different cycle? Could an orbit continue forever without ever repeating a value?

These possibilities take us back to the conjecture itself. Every positive integer is conjectured to eventually reach 1 and enter the same period-3 cycle.

Although enormous ranges of starting values have been checked by computer, there is still no proof that this must happen for every positive integer.

THE BIG IDEA

We know exactly what the Collatz function does at each step. What remains mysterious is whether those simple rules always produce the same long-term behaviour.
